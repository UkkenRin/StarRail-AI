# Android 实体屏 Live Vision：本地只读采集第一阶段

> 状态：实现源码已提交；CI 编译与真机验收分别核对。**不是 AI 代打、OCR、模型输入或自动触摸。**

## 与原版虚拟屏的区别

原版三月七小助手会给游戏创建独立的后台虚拟显示器。本功能使用用户授权的 Android MediaProjection 采集**真实显示器或系统选中的应用画面**，ImageReader 在采集用的 VirtualDisplay 中接收像素，**不会另外启动一个游戏实例**。两个模式的画面与输入权并不共用。

## 已实现的第一阶段

- AI 顾问页提供「授权并开始本地观察」，每次会话必须经系统确认。
- 独立前台服务维护授权会话；系统通知和 AI 页面都可停止。系统结束共享或应用被终止会释放资源。
- 每秒至多取约一帧，把预览缩小到长边 640 像素，仅保留在进程内存；**不会写入文件、发送云端或调用 GPT，也不会触摸游戏**。
- 在 AI 页面查看帧数、原采集尺寸、最近画面并清除预览。手动停止会暂留最后一帧，供你返回 AI 页面查看；进程关闭后不持久保存。
- Android 14+ 使用 mediaProjection 前台服务，每次授权只创建一个投影会话；系统内容尺寸变化通过 resize/setSurface 处理，不重复消耗授权。

## 在 iQOO Pad5 Pro / OriginOS 上验证

1. 使用通过 Android CI 的新实验 APK，在「AI 顾问」页点击「授权并开始本地观察」。
2. 系统弹窗选择共享整个屏幕或星铁应用（实际选项由系统决定）并确认，切换到游戏等待数秒。
3. **保持游戏在前台时**，从通知栏点击「停止观察」。返回 AI 页面，查看是否有最后一帧和采样计数。
4. 点击「清除本机预览」。再次启动应该再次出现系统授权；锁屏或系统结束共享也应该使会话停止。
5. 首次验收不建议并行启动原版 M7A 的虚拟屏任务，避免混淆两块不同屏幕的画面。

注意：投屏授权可能暴露整个屏幕，包括通知和其他应用。**本阶段还未验证当前截图一定是星铁，不可在此基础上自动点击。** 屏幕采集时请勿浏览敏感资料。

## 实现与限制

源码：Android overlay 中的 CaptureGeometry、LocalCaptureFrames、StarRailCaptureService，及 overlay 注入的 AndroidManifest 权限/服务声明。已有 Python patch 测试和 Android Kotlin 尺寸测试。构建仍使用固定版 March7thAssistant v2026.11.17；本功能不代表 APK 完全独立于上游，也不等于真机已验证。
